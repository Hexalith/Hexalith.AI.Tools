# Hexalith.AI.Tools

AI tooling for the Hexalith ecosystem: the home for **Claude/Codex instructions
for developing Hexalith modules**, plus the matching skills, workflows, commands,
and job automation.

## Agent instructions

- [`CLAUDE.md`](./CLAUDE.md) — for Claude / Copilot / Cursor: the authoritative,
  self-contained guide to developing Hexalith modules.
- [`AGENTS.md`](./AGENTS.md) — for Codex and other agents: Codex-specific notes
  that reference `CLAUDE.md`.

`CLAUDE.md` is the single source of truth; `AGENTS.md` points to it. When this
repository is consumed as a submodule, the host repository's own instructions
take precedence on conflict.

## Contents

- **Agent entry points** — `CLAUDE.md`, `AGENTS.md` (above)
- **Topical instructions** — `hexalith-llm-instructions.md`,
  `hexalith-ux-instructions.md`
